## Delivered contract

FutureShops now has an additive immutable account binding seam in the public economy API.

* `PersistedAccountBindingV1` validates and carries provider, adapter protocol, backend class and fingerprints, durable lineage, account UUID, currency precision, manager identity, binding generation, root and leg request IDs, request fingerprint, and receipt protocol.
* `RuntimeBindingProofV1` carries allowlisted class loader and descriptor evidence plus non serialized account, `FEPlayerData`, and manager references. Object references never enter the codec.
* `BoundEconomyOperationV1` requires actor and leg identity to match the persisted binding and keeps required capabilities separate from provider declarations and account observed capabilities.
* `AccountBindingCodecV1` provides a version one bounded binary round trip with schema and trailing data checks.
* `OperationRequest` and `RequiredCapabilities` provide additive public entry types without importing optional platform classes.
* `LegacyBindingClassifier` classifies old records as compatible, unresolved hybrid, or unprovable. The coordinator refuses an unbound legacy Pixelmon hybrid record during recovery and freezes it for original proof.

`EconomyTransactionCoordinator` registers a binding once per request UUID and rejects changed immutable identity. Bound precheck, mutation, lookup, and retry validate the same binding before delegating. The effective capability gate intersects required, provider declared, and independently observed sets. A convenience bind without runtime proof is deliberately not admissible and returns `CAPABILITY_MISSING`; it cannot turn provider booleans into account proof. New typed reasons include `REQUEST_CONFLICT`, `BINDING_CHANGED`, and `INVALID_PRECISION`.

Existing `MutationRequest` routes remain source compatible. Existing valid internal, native, DanConomy, and separately proven Vault fixtures continue through the previous coordinator path until the exact runtime protocol is selected by later Phase 004 tasks. No production Pixelmon hybrid mutation path was enabled.
